# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 批量受理导入以行为单位独立生效：逐行校验，某行被拒绝不影响其他行受理，也不产生流水；同一份提交内重复出现的行只按第一次生效，重复行拒绝；订单标识已存在的行按重复受理拒绝，不修改已有订单与流水；金额非正整数、币种不支持、必填标识缺失或为空的行拒绝。导入结果逐行给出结论：成功行给出新订单结果金额，拒绝行给出可区分原因。同一份提交重复导入时，已生效行不重复受理、被拒行仍被拒绝，重放不改变既有订单与流水。
- 条件检索按租户与筛选条件（订单状态、币种、订单金额区间、已收金额区间、累计冲正金额区间、是否发生过冲正）查询订单，按订单标识升序稳定分页，无新收付变动时翻页不重不漏。检索请求带去重标识：标识检索请求本身，与订单标识相互独立，租户内唯一；同一去重标识重复检索只返回首次的同一结果集且不写入。跨租户或未提供租户的检索不泄漏其他租户订单；无命中返回空列表；参数非法给出可区分原因且不写入。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额；累计到订单金额时订单进入已结清（settled）。
- 冲正（退款）以独立的业务标识登记：业务标识在租户内唯一，标识冲正操作本身，与订单标识相互独立，不得混用。
- 同一（租户, 业务标识）的重复请求视为重放：首次生效一次并返回冲正记录，重放返回同一记录，不重复减少已收、不重复累计冲正、不新增流水。不同业务标识即使金额相同也分别生效。
- 冲正金额必须为正整数，且不得超过可退余额 = 已收金额 − 累计冲正金额；超出、非正数或金额非法一律拒绝，订单金额、已收、累计冲正与既有流水均不改变。
- 冲正不改变已收金额，累计冲正单调增加，未收金额仍等于订单金额减已收金额；可退余额随每次冲正单调下降。结清后仍可在可退余额范围内冲正。
- 作废以独立的业务标识登记：业务标识在租户内唯一，标识作废操作本身，与订单标识、冲正业务标识、冲销业务标识独立，不得混用。仅未发生收款的订单可作废，已收大于零一律拒绝；生效后进入已作废（voided）终态，此后收款、冲正、冲销、再作废一律拒绝且无任何变更；不改订单金额与既有流水，仅追加一条作废流水。同一作废标识重复请求视为重放，返回首次的同一记录并标记重放，不重复写流水、不改状态；同租户将该标识用于另一订单的作废或冲销时拒绝且状态不变；不同标识各自生效。订单不存在或跨租户按不存在处理，不泄漏是否存在，也不产生流水。
- 冲销以独立的业务标识登记：业务标识在租户内唯一，标识冲销操作本身，与订单标识、冲正业务标识、作废业务标识独立，不得混用。冲销金额必须为正整数，且不得超过 已收 − 累计冲正 − 累计冲销；超出或非正数一律拒绝，订单金额、已收、累计冲正、累计冲销与流水均不变。冲销不改已收与累计冲正，累计冲销单调增加；未收仍等于订单金额减已收，可退余额仍等于已收减累计冲正，均不受冲销影响。同一冲销标识重复请求视为重放，返回首次的同一记录并标记重放，不重复累计、不新增流水；不同标识各自生效。
- 收款冲正修正以独立的业务标识登记：业务标识在租户内唯一，标识修正操作本身，与订单标识、冲正、作废、冲销及取消修正的业务标识独立，不得混用。修正金额必须为正整数，且不得超过 已收 − 累计冲正 − 累计冲销；超过已收、非正数或金额非法一律拒绝，订单金额、已收、累计冲正、累计冲销与既有流水均不变。生效后已收减少、未收增加，订单金额与累计冲正、累计冲销不改，仅追加一条修正流水；已收恢复后按既有口径重判订单状态（跌破订单金额回到已受理，达到终态口径进收付完结），可退余额等于已收减累计冲正、累计冲销上限同既有口径，随修正结果同步变化。同一修正标识重复请求视为重放，返回首次的同一记录（含是否已取消标记）并标记重放，不重复扣减、不新增流水；不同标识各自生效。
- 取消冲正修正以独立的业务标识登记：业务标识在租户内唯一，标识取消操作本身，与被取消修正的业务标识及订单标识相互独立，不得混用。请求含本次取消的业务标识与被取消修正的业务标识，取消金额取被取消修正的原始金额，不可指定；仅已生效且未被取消的修正可取消。生效后已收恢复、未收减少，订单金额与累计冲正、累计冲销及既有流水不改，仅追加一条取消流水，并将被取消修正标记为已取消。被取消修正不存在、已被取消、订单不匹配或恢复后已收会超过订单金额一律拒绝，订单金额、已收、累计冲正、累计冲销与流水均不变，错误原因可区分。同一取消标识重复请求视为重放，返回首次的同一记录并标记重放，不重复恢复、不新增流水；不同标识各自生效。
- 修正与取消遵守既有状态与终态规则：已作废或已进入收付完结终态的订单一律拒绝且无任何变更。并发交错的收款、冲正、作废、冲销与修正、取消不得使已收超过订单金额，也不得使累计冲正、累计冲销越过其既有上限；每个多步写操作在单事务内完成，任一步骤失败整体回滚，无半更新。
- 收付终态（completed）当且仅当已收大于零且 可退余额 − 累计冲销 归零；终态不可逆，此后收款、冲正、冲销、作废、修正、取消修正一律拒绝且无任何变更。结清（settled）不等于终态，结清后仍可在可退余额范围内冲正或冲销。作废与终态互斥：无收款订单只能作废、不进终态；进终态订单必已收款、不可作废。
- 每次受理、收款、冲正、作废、冲销、冲正修正、取消冲正修正与退款单执行到账、执行冲正都写入按租户隔离的收付流水，按（租户, 订单）内发生顺序递增编号，记录操作类型、业务标识（若提供）、金额与结果金额（已收、未收、累计冲正、累计冲销）。
- 跨租户读取、收款、冲正、作废、冲销、冲正修正、取消冲正修正、退款单执行冲正与流水查询一律按“不存在”处理，不得泄漏对象是否存在，也不产生流水。
- 修正与取消记录持久化：重启后订单金额、已收、累计冲正、累计冲销、修正与取消记录、流水仍与持久化一致，重放同一请求只生效一次。
- 金额以最小货币单位的整数表示，不使用浮点数；所有多步写操作在单事务内完成，任一步骤失败整体回滚，不出现半更新。

## 退款单（refund order）

- 退款单独立于订单收款冲正登记：它是登记在原订单之下的独立单据，带自身单据标识（租户内唯一），记录申请退款金额与实退金额。退款单标识、退款单冲正业务标识与订单侧业务标识（冲正/作废/冲销/冲正修正/取消修正）共用同一唯一性命名空间，不得混用；受理或冲正时标识冲突一律拒绝且不改任何数据。
- 受理：请求给出租户、退款单标识、原订单标识与申请退款金额（最小货币单位正整数）。同一（租户, 退款单标识）重复受理返回首次的同一单据且不新建，响应标记为重放；同一标识但原订单标识或申请金额不一致时拒绝。原订单不存在或跨租户按不存在处理。退款单可受理在任意状态（含已作废、已收付完结）的订单上；受理本身不动原订单账。
- 生命周期：`accepted`（已受理）审核后进入 `approved`（通过）或 `rejected`（驳回）。驳回只允许对已受理未审核的退款单生效，驳回后不可执行、可撤销。通过后的退款单可执行：执行结果为到账（`succeeded`）或失败（`failed`）；失败记录失败原因，可再次执行。撤销仅允许对已受理、已驳回或执行失败的退款单生效，撤销后进入已撤销终态且不可再执行；审核通过待执行与已到账、已冲正不可撤销。已到账（`succeeded`）退款单可执行冲正，冲正后进入已冲正（`reversed`）终态。
- 执行到账与原订单收付账联动：执行时把实退金额计入原订单的累计冲正，实退金额必须为正整数且不超过原订单当时可退余额（= 已收 − 累计冲正）；超过则整体拒绝，退款单保持已通过待执行，不产生流水与状态变化。到账成功后退款单进入已到账并落库实退金额，追加一条原订单退款流水（冲正流水业务标识记退款单标识），并按既有口径重判原订单状态（可进入收付完结终态）。重复执行到账返回同一结果，不重复入账、不重复写流水。
- 执行在原订单已作废、已进入收付完结终态、已被删除或跨租户时按不存在处理并整体拒绝，不产生流水与状态变化。
- 执行冲正（refund reversal）以独立的业务标识登记：业务标识在租户内唯一，标识本次冲正操作本身，与退款单标识、原订单标识及订单侧冲正、作废、冲销、冲正修正、取消修正的业务标识独立，不得混用。仅状态为已到账的退款单可执行冲正；其他状态（已受理、审核通过、审核驳回、执行失败、已撤销、已冲正）一律拒绝且无任何变更。冲正金额取该退款单已落库的实退金额，调用方不可指定（必为正整数）。冲正生效后，在原订单累计冲正中扣减该实退金额（累计冲正单调减少这次的量，只扣减本单实退、不影响同单其他冲正），追加一条原订单冲正流水（业务标识记本次冲正的业务标识，金额记实退金额，操作类型为退款单冲正），并按既有口径重判原订单状态（曾被到账送入收付完结终态的订单冲正后回到非终态）；订单金额、已收、累计冲销及既有流水不改。同一（租户, 冲正业务标识）的重复请求视为重放：返回首次的同一记录（含重放标记与当时订单结果金额），不重复扣减、不新增流水；同一退款单以不同业务标识再次执行冲正、或冲正后再次执行到账，一律拒绝且无任何变更。冲正业务标识已被订单侧任一操作占用、或与已存在的其他操作标识（含其他退款单冲正、退款单标识）冲突时返回 409 且状态不变；退款单不存在或跨租户、原订单已不存在的，按不存在处理返回 404，不泄漏是否存在、不产生流水与状态变化。冲正后退款单进入已冲正终态并落库冲正的业务标识，此后审核、执行到账、执行失败、撤销、再冲正一律拒绝；重放判定以本次冲正的业务标识为准，与退款单标识互不干扰。
- 任意驳回、撤销、执行或冲正拒绝都在单事务内整单回滚关联写入，不留下半更新；驳回与撤销的状态均未与原订单收付账联动（只有到账才入账），故无需回滚原订单账；冲正的累计冲正扣减、冲正流水与退款单终态在同一事务内整单完成，任一步失败整体回滚。
- 退款单持久化：服务重启后退款单状态、申请/实退金额、冲正业务标识与原订单累计冲正、冲正流水仍一致，同一执行或冲正请求重放只生效一次。
- 条件检索退款单支持按退款单状态（含已冲正终态）、是否已冲正、原订单标识、申请金额区间过滤，按退款单标识升序稳定分页，无新受理时翻页不重不漏；检索请求带租户内唯一的去重标识，同一去重标识重放返回首次同一结果集且不写入，冲正等后续状态变化不改变既有快照。无命中返回空列表；参数非法给出可区分原因且不写入；检索按租户隔离，跨租户不泄漏其他租户退款单。
- 每张退款单可按标识读取，含状态、申请金额、实退金额（到账前为空）、失败原因、关联的原订单标识与冲正业务标识（未冲正为空）；不存在或跨租户按不存在处理，不泄漏对象是否存在。

# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额；已收累计到订单金额时订单进入 `settled`。
- 可退余额 = 已收金额 − 累计冲正；冲正金额为正整数且不得超过可退余额，随每次冲正单调下降。
- 冲正不改变已收金额，只增加累计冲正；可退余额归零后订单进入 `closed` 终态，后续冲正一律拒绝且不产生变更。
- 冲正以（租户, 业务标识）唯一；同一业务标识的重放返回首次的冲正记录，不重复生效；业务标识与订单标识相互独立。
- 每次受理、收款、冲正写入按租户隔离、按 `seq` 递增的收付流水，含操作类型、业务标识（若有）、金额与结果金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。

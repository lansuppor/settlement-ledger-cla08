# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 批量受理导入以行为单位独立生效：逐行校验，某行被拒绝不影响其他行受理，也不产生流水；同一份提交内重复出现的行只按第一次生效，重复行拒绝；订单标识已存在的行按重复受理拒绝，不修改已有订单与流水；金额非正整数、币种不支持、必填标识缺失或为空的行拒绝。导入结果逐行给出结论：成功行给出新订单结果金额，拒绝行给出可区分原因。同一份提交重复导入时，已生效行不重复受理、被拒行仍被拒绝，重放不改变既有订单与流水。
- 条件检索按租户与筛选条件（订单状态、币种、订单金额区间、已收金额区间、累计冲正金额区间、是否发生过冲正）查询订单，按订单标识升序稳定分页，无新收付变动时翻页不重不漏。检索请求带去重标识：标识检索请求本身，与订单标识相互独立，租户内唯一；同一去重标识重复检索只返回首次的同一结果集且不写入。跨租户或未提供租户的检索不泄漏其他租户订单；无命中返回空列表；参数非法给出可区分原因且不写入。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额；累计到订单金额时订单进入已结清（settled）。
- 冲正（退款）以独立的业务标识登记：业务标识在租户内唯一，标识冲正操作本身，与订单标识相互独立，不得混用。
- 同一（租户, 业务标识）的重复请求视为重放：首次生效一次并返回冲正记录，重放返回同一记录，不重复减少已收、不重复累计冲正、不新增流水。不同业务标识即使金额相同也分别生效。
- 冲正金额必须为正整数，且不得超过可退余额 = 已收金额 − 累计冲正金额；超出、非正数或金额非法一律拒绝，订单金额、已收、累计冲正与既有流水均不改变。
- 冲正不改变已收金额，累计冲正单调增加，未收金额仍等于订单金额减已收金额；可退余额随每次冲正单调下降。
- 作废以独立的业务标识登记：业务标识在租户内唯一，标识作废操作本身，与订单标识、冲正业务标识独立，不得混用。仅未发生收款的订单可作废，已收大于零一律拒绝。生效后订单进入已作废终态（voided），此后收款、冲正、冲销、再作废一律拒绝且无任何变更；作废不改订单金额与既有流水，仅追加一条作废流水。同一（租户, 作废标识）重复请求视为重放：返回首次的同一记录，不重复写流水、不改状态；同租户将该标识用于另一订单的作废或用于冲销一律拒绝且状态不变；不同标识各自生效。
- 冲销以独立的业务标识登记：业务标识在租户内唯一，标识冲销操作本身。冲销金额必须为正整数，且不得超过 已收金额 − 累计冲正 − 累计冲销；超出或非正数一律拒绝，订单金额、已收、累计冲正、累计冲销与既有流水均不改变。冲销不改变已收与累计冲正，累计冲销单调增加；未收仍等于订单金额减已收，可退余额仍等于已收减累计冲正，均不受冲销影响。同一（租户, 冲销标识）重复请求视为重放：返回首次的同一记录，不重复累计、不新增流水；不同标识各自生效。
- 终态不变式：订单进入已收付完结终态（completed）当且仅当已收大于零且 可退余额 − 累计冲销 归零；终态不可逆转，此后收款、冲正、冲销、作废一律拒绝且无任何变更。结清（settled）不等于终态，结清后仍可在可退余额范围内冲正或冲销。作废与终态互斥：无收款订单只能作废、不进终态；进终态订单必已收款、不可作废。
- 每次受理、收款、冲正、作废与冲销都写入按租户隔离的收付流水，按（租户, 订单）内发生顺序递增编号，记录操作类型、业务标识（若提供）、金额与结果金额（已收、未收、累计冲正、累计冲销），与既有流水连贯解释状态由来。
- 跨租户读取、冲正、作废、冲销与流水查询一律按“不存在”处理，不得泄漏对象是否存在，也不产生流水。
- 金额以最小货币单位的整数表示，不使用浮点数；所有多步写操作在单事务内完成，任一步骤失败整体回滚，不出现半更新。
